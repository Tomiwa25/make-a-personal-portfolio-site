# Modern Software Engineer Portfolio

A responsive, high-performance software engineer portfolio designed specifically for attaching to resumes, CVs, and job applications. Engineered to showcase real-world system architecture, measurable business impact, and technical depth.

## 🚀 Key Features

- **Executive ATS-Ready Resume (CV)**: Interactive printable resume view formatted cleanly for recruiters with 1-click **Print / Save as PDF**.
- **System Architecture Deep-Dives**: Project case study modal highlighting technical challenges, distributed system solutions, and measurable impact metrics (e.g. latency, throughput, scale).
- **Interactive Skills Matrix**: Categorized technical skills filterable by domain (Frontend, Backend, Databases, Cloud & DevOps) with live real-time search.
- **Career Timeline**: Reverse-chronological experience roadmap with quantifiable achievements and technology badges.
- **Dark / Light Theme Toggle**: Seamless mode switching with preference saved in `localStorage`.
- **Live On-Page Customizer**: In-browser profile editor to test and preview personal information instantly.
- **Direct Contact & 1-Click Email Copy**: Direct copy button with toast alert and pre-populated mail client launcher.

---

## 🛠️ How to Personalize Your Information

### Option 1: Live On-Page Customizer
1. Click the **"Customize Info"** button in the top navigation bar.
2. Edit your name, title, bio, email, location, GitHub, and LinkedIn links.
3. Click **"Save & Update Site"** to see changes immediately reflected!

### Option 2: Edit `profile-data.js` Directly
Open `profile-data.js` to customize:
- `personal`: Name, role, contact details, social URLs, and bio.
- `skills`: Add or modify programming languages, frameworks, databases, and cloud tools.
- `projects`: Add your top software projects, live demo links, repository links, and architectural notes.
- `experience`: Update your work history, companies, dates, and bullet points.
- `education`: Update degrees, colleges, and honors.
- `certifications`: Add AWS, CKA, or other credentials.

## 📄 Attaching to Your CV / Resume

When sending your CV to hiring managers or recruiters:
1. Place your live portfolio URL right under your name and contact info at the top of your resume:
   ```text
   Portfolio: https://your-portfolio-link.com
   ```
2. When recruiters open your site, they can explore live demos, examine code architecture, or click **"View CV"** to print an executive ATS-formatted PDF version directly.
